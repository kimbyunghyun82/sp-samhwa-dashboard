## 안내

이 와이어프레임은 실제 서비스가 아니라, PRD 논의를 위한 저해상도 목업입니다. 제품별 고객 반응, 채널별 언급량, 지역별 관심도 등의 수치와 고객 리뷰 인용문은 화면 구조를 보여주기 위한 예시 데이터이며, 실제 수집된 데이터가 아닙니다. 반면 SP SAMHWA·노루페인트·KCC의 제품명과 언론보도 출처 링크는 실제 확인된 정보입니다.
